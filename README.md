# Building

- Run `dotnet run` in `/bld` to generate the build scripts
- Run `/bld/win_e_sqlite3_v142_plain_x64.bat` to build the windows binary
- The output is in `/bld/bin/e_sqlite3/win/v142/plain/x64`

# cb

This repo contains SQLite, SQLite3 Multiple Ciphers and SQLCipher for SQLitePCL.raw, and the scripts to construct them.
